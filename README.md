# Nagmat Portfolio

A multi-page static portfolio website for a Software Engineer.

## Pages
- `index.html` — home page
- `about.html` — about page
- `projects.html` — projects page
- `contact.html` — contact page

All pages are plain HTML files and link to each other.

## Static Assets
- `styles.css` and `scripts.js`
- `assets/profile.svg`
- `assets/resume.txt`

## GitHub Pages
This repository is ready for GitHub Pages hosting:
1. Push to your GitHub repository.
2. In **Settings → Pages**, set **Source** to **Deploy from a branch**.
3. Select the branch and `/ (root)` folder.
4. Save; your site will be served from `index.html`.

A `.nojekyll` file is included for direct static file serving.
